## Why this exists

Official docs describe features. This guide teaches **staff judgment**: when to use a skill vs a hook vs a subagent vs MCP — with labs you run in your own repo.

You do **not** need Claude open to learn. Read here, copy templates, practice in the terminal.

## How to move through it

<CardGrid>
  <Card title="1. Find your level" icon="approve-check">
    Use the [roadmap](/guides/roadmap/) checkboxes — no quiz bot, no tokens.
  </Card>
  <Card title="2. Work a module" icon="document">
    Open a module, follow the walkthrough, save work under `lessons/artifacts/`.
  </Card>
