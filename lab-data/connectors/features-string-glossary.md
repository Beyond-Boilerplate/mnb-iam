# Connector `featuresString` glossary (IdentityIQ)

| Feature | Meaning |
| --- | --- |
| `PROVISIONING` | Connector can create/modify/delete accounts |
| `SYNC_PROVISIONING` | Supports synchronous plan execution |
| `ENABLE` | Enable/disable account operations |
| `UNLOCK` | Unlock locked accounts |
| `PASSWORD` | Password set/change |
| `CURRENT_PASSWORD` | Requires current password for change |
| `AUTHENTICATE` | Can authenticate users (pass-through) |
| `SEARCH` | Random access / search accounts |
| `DISCOVER_SCHEMA` | Schema discovery from target |
| `MANAGER_LOOKUP` | Manager resolution from target |
| `DIRECT_PERMISSIONS` | Direct permission model (not only groups) |
| `NO_RANDOM_ACCESS` | Iterate-only (typical delimited/LDIF) |
| `COMPOSITE` | Logical/composite application |
| `UNSTRUCTURED_TARGETS` | Unstructured target support |
| `PROXY` | Proxied/MIM style connector |

Read features on each Application template in Debug → `ConnectorRegistry` before promising a control to Risk.
